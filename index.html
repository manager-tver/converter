Частые вопросы

Мои файлы загружаются на сервер?

Нет. Вся конвертация происходит локально в вашем браузере с помощью JavaScript-библиотек (PDF.js, Mammoth, SheetJS и др.). Файлы никуда не отправляются.

Какие конвертации работают лучше всего?

PDF → JPG/PNG/TXT, DOCX → PDF/TXT/HTML, JPG/PNG → PDF, XLSX → PDF/CSV/JSON, TXT/HTML/MD → PDF/DOCX. Для сложных макетов Word результат может немного отличаться от оригинала.

Есть ли ограничения по размеру?

Официально — до 100 МБ, но на слабых устройствах большие PDF могут тормозить. Для пакетной обработки лучше конвертировать по одному файлу.

Можно ли конвертировать несколько файлов сразу?

Да, включите режим «Пакетно» и выберите несколько файлов — каждый будет сконвертирован по очереди.
